# 🛡️ CHAINSCOPE (Local Web3 Lab)
> **ทำความเข้าใจและทดสอบ Smart Contract ให้ปลอดภัย ก่อนส่งขึ้นบล็อกเชนจริง**

CHAINSCOPE เป็นเครื่องมือ Interactive Sandbox ที่ถูกออกแบบมาเพื่อให้นักพัฒนา (Developers) และผู้สนใจ Web3 สามารถวิเคราะห์ ตรวจสอบความเสี่ยง และทดสอบการทำงานของ Smart Contract ได้ง่าย สะดวก และโปร่งใสที่สุด

---

## 🎯 วิสัยทัศน์และแนวคิดโครงการ (Project Philosophy)

1. **ทำเรื่องยากให้เป็นเรื่องง่าย (Simplicity & Transparency):**
   โค้ด Smart Contract หรือ ABI ซับซ้อน จะถูกแปลงผลเป็นแผนภูมิ (Visual Analytics) และสรุปความเสี่ยงด้วยภาษาไทยที่เข้าใจง่าย เพื่อให้ทุกคนมองเห็นโครงสร้างจริงก่อน Deploy

2. **ผู้ใช้เป็นเจ้าของข้อมูลและตัวตน (On-chain Identity):**
   เข้าใช้งานผ่าน On-chain Name เช่น `.eth` (ENS) ร่วมกับระบบความปลอดภัยส่วนตัว โดยไม่มีการดึงหรือเก็บข้อมูลความลับไว้ที่เซิร์ฟเวอร์ส่วนกลาง (Client-Side Only)

3. **ปลอดภัยและเป็นกลาง (Security & Neutrality):**
   ระบบเน้นการจำลองการทำงาน (Simulation) บนเครื่องของผู้ใช้เอง ปราศจากการครอบงำข้อมูลหรือการแอบอ้างสิทธิ์ เพื่อให้ชุมชนนำไปต่อยอดและใช้งานจริงได้อย่างมั่นใจ

---

## 🚀 ฟังก์ชันหลัก (Key Features)

- **On-chain Auth:** ล็อกอินด้วยชื่อ `.eth` หรือ Wallet Address พร้อมระบุ Passcode เข้าใช้งาน
- **Contract Workspace:** แปะ Source Code (Solidity) หรือ ABI เพื่อเริ่มสแกนโครงสร้างทันที
- **Visual Analytics:** แสดงสัดส่วน Token Allocation และโครงสร้างสัญญาด้วยกราฟที่ชัดเจน
- **Security Auditor:** ระบบตรวจเช็คความเสี่ยงเบื้องต้น (Static Analysis) พร้อมสรุปผลภาษาไทย
- **Local Simulation:** จำลองการทำงานของฟังก์ชันโดยไม่ต้องเสียค่า Gas จริง
- **Farcaster Frame Ready:** รองรับการเปิดใช้งานเป็น Mini App บน Farcaster / Warpcast
